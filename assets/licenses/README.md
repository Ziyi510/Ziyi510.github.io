# 模板与素材来源

主页的配色、字体、卡片布局和地图样式参考 [ChenAnno/ChenAnno.github.io](https://github.com/ChenAnno/ChenAnno.github.io)。保留其 MIT 许可于 `chenanno-LICENSE.txt`。

- `assets/fonts/charis/`：Charis SIL 字体及其 OFL 许可。
- `images/visitor-map.svg`：参考仓库的点阵世界地图底图，基于 Natural Earth。
- `images/logo-nus.png`：参考仓库使用的 NUS 校徽，仅用于标识教育经历。

浏览地图目前仅显示底图，不含访客记录。将站点自己的地图嵌入地址填入 `_config.yml` 的 `visitor_map_embed_url` 后即可显示统计地图；不要使用参考站的统计接口或记录。

## 教育经历标志

- `images/logo-ntu.svg`：来自 [NTU 校徽文件页](https://en.wikipedia.org/wiki/File:Nanyang_Technological_University_coat_of_arms_vector.svg)，并与 [NTU 官方标志](https://www.ntu.edu.sg/ResourcePackages/NTU/assets/images/NTU_Logo.png)核对。
- `images/logo-vt.png`：来自 [Virginia Tech 官方品牌页面](https://brand.vt.edu/licensing/university-trademarks.html)的竖版大学标志。

学校标志归各大学所有，用于标识本人的教育经历，不属于模板的 MIT 许可范围。
